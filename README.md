# VISIO — Haute Lunetterie & Luxury Eyewear Website

An ultra-premium, interactive multi-page luxury eyewear web experience designed with dark luxury aesthetics, gold accents, smooth micro-animations, and responsive layout.

---

## 🌟 Live Pages Included

1. **`index.html`** — **Exclusive 2026 Hero Showcase**
   - High-impact fullscreen slider with 5 designer eyewear models.
   - Smooth animated slide transitions, radial ambient glow, and auto-play progress bar.
   - Interactive 3D mouse parallax tilt effect on glasses.
   - Keyboard arrows (`←` / `→`) and touch/swipe mobile support.

2. **`sunglasses.html`** — **The Sunglasses Collection**
   - Luxury product grid with filter tabs (*All*, *Polarized UV400*, *24K Gold*, *Italian Acetate*).
   - Dynamic sorting (Price low/high, Highest rated).
   - Integrated Virtual Try-On AR simulation modal.

3. **`optical.html`** — **Prescription & Blue-Light Atelier**
   - Interactive Lens Customizer (*Blue Shield Plus*, *Diamond Anti-Glare*, *Adaptive Transitions*, *1.74 Ultra Thin*).
   - Live optical rendering preview and prescription configuration.

4. **`craft.html`** — **Titanium Craft & Haute Metallurgy**
   - Interactive exploded frame diagram with clickable engineering hotspots.
   - Deep-dive into aerospace beta-titanium, diamond chamfering, and 24K gold plating.

5. **`atelier.html`** — **Bespoke Atelier & VIP Booking**
   - Private styling consultation and bespoke frame commission form.
   - Global flagship directories (Paris, Milan, New York, Tokyo).

## 🚀 How to Publish on GitHub Pages (Free)

1. **Upload to GitHub**:
   - Create a new repository on [GitHub](https://github.com/new) (e.g. `visio-luxury-eyewear`).
   - Drag and drop or push the files from this folder (`index.html`, `sunglasses.html`, `optical.html`, `craft.html`, `atelier.html`, and `assets/`).

2. **Enable GitHub Pages**:
   - Go to your repository **Settings** tab.
   - Scroll to **Pages** in the left sidebar.
   - Under **Build and deployment** > **Branch**, select `main` (or `master`) and `/ (root)`.
   - Click **Save**.

3. **Your Live Website is Ready**:
   - Within 1–2 minutes, your website will be live at:
     ```
     https://<your-username>.github.io/<your-repo-name>/
     ```
